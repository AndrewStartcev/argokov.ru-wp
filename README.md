# Argokov WordPress Theme

WordPress-интеграция чистой вёрстки из `AndrewStartcev/argokov.ru`.

- `front-page.php` — главная.
- `page-*.php` — статические разделы.
- `archive-material.php`, `single-material.php` — материалы.
- `archive-case.php` — кейсы.
- `functions/` — служебная логика.
- `acf-json/` — ACF Local JSON.
- `assets/` — исходные CSS, JS, изображения и шрифты.

Правила интеграции: `docs/INTEGRATION.md`.
